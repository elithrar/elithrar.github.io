# Color desktop references (NS37–NS40)

These four screenshots were supplied by the user after reviewing the first NeXTSTEP implementation. They extend the 36 original-manual illustrations to a **40-image target corpus**. The fifth supplied color screenshot, IMG_0613.png, repeats the File Viewer composition at a smaller scale and is not counted again. IMG_0609.png is evidence of the previous blog failure, not a NeXTSTEP reference.

These are the appearance authority for this blog: purple workspace, medium-gray surfaces, compact menus, window proportions and shaded application artwork. The original manual remains the authority for behavior and component anatomy. Original provenance beyond the supplied attachments is unknown; do not claim these were captured by us or give them invented source URLs. Their pictured application artwork is reference material, not distributed product assets.
