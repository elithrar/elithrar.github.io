# Blog application artwork

Original SVG illustrations created for this project and covered by the repository's MIT license. They are interpretations of the paper, leather and CRT object vocabulary in the user-supplied NeXTSTEP references NS38–NS40, not extracted NeXT assets, copied logos or authentic historic icons.

All four use a 48×48 coordinate system, hard silhouettes, shaded material facets and a consistent upper-left light source. The colored illustrations are intentionally distinct from the flat gray system chrome. Recents adds a pencil to the shared printed-document vocabulary; Archive is a leather file case; About is a CRT information terminal. Archive files and miniwindows use the document illustration.

The previous Haiku assets remain attributed in their original directory as historical material but are no longer loaded by the interface.
