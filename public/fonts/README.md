# Newsreader fonts

Body text uses the 16pt optical-size cuts of Newsreader, from [Production Type's Newsreader repository](https://github.com/productiontype/Newsreader/tree/cfcb4f7af0e52c25e8df2a2431814c8e5fe2e155/fonts/static/woff2). Regular, bold, italic, and bold italic are served locally as WOFF2. The commit suffix versions the files for the Worker's immutable font cache.

The existing Latin-subset Newsreader Medium Italic v26 font remains dedicated to editorial headings. All files are covered by the adjacent OFL.txt license.
