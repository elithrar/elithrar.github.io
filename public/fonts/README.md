# Vendored fonts

Body copy uses EB Garamond from Google Fonts, with locally served Latin-subset variable WOFF2 files for roman and italic. The CSS exposes weights 400–700, including regular, medium, and bold, without a Google Fonts runtime request. The v33 filename versions the assets for the Worker's immutable font cache.

Source: https://fonts.google.com/specimen/EB+Garamond

Google Fonts CSS request: https://fonts.googleapis.com/css2?family=EB+Garamond:ital,wght@0,400..700;1,400..700&display=swap

Pinned download URLs:

- eb-garamond-latin-italic-400-700-v33.woff2: https://fonts.gstatic.com/s/ebgaramond/v33/SlGWmQSNjdsmc35JDF1K5GRweDs1Zw.woff2
- eb-garamond-latin-normal-400-700-v33.woff2: https://fonts.gstatic.com/s/ebgaramond/v33/SlGUmQSNjdsmc35JDF1K5GR1SDk.woff2

EB Garamond is covered by EB-Garamond-OFL.txt. The existing Newsreader Medium Italic v26 font remains dedicated to editorial headings and is covered by OFL.txt.
